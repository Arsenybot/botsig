# Telegram-бот мониторинга баланса SigmaSMS + Админ-панель

Профессиональный сервис мониторинга баланса пользователей SigmaSMS в режиме реального времени с Telegram-ботом (@SigmaBa1ance_bot), оповещениями по настраиваемым порогам (1 000 ₽, 5 000 ₽, 10 000 ₽ и пользовательские) и веб-панелью управления на React + Express.

---

## 🔒 Безопасность токенов
- Токены хранятся в изолированном хранилище (`data/.vault/`) с шифрованием **AES-256-GCM** и деривацией ключа **PBKDF2-HMAC-SHA512** (100 000 итераций).
- В API и веб-интерфейсе токены всегда санитизируются и маскируются (например, `49b3••••••••••••••••••••••••••••••••9e73`).
- База данных пользователей (`data/bot_database.json`) не содержит открытых токенов.

---

## 🚀 Быстрый запуск в Docker локально

```bash
# 1. Скопируйте переменные окружения
cp .env.example .env

# 2. Запустите через docker-compose
docker compose up -d --build

# Сервис и веб-панель будут доступны на http://localhost:3000
```

### Шаг 2. Создание Container App в Cloud.ru

1. Войдите в **[Cloud.ru Console](https://console.cloud.ru/)**.
2. В боковом меню перейдите в раздел **Container Apps** (или Serverless Containers).
3. Нажмите кнопку **«Создать ресурс»** -> **Container App**.
4. **Источник сборки (Source)**:
   - Выберите **GitHub**.
   - Авторизуйте Cloud.ru в вашем аккаунте GitHub.
   - Выберите созданный репозиторий и ветку `main`.
5. **Сборка (Build Settings)**:
   - Сборщик автоматически обнаружит `Dockerfile` в корне проекта.
   - Контекст сборки: `/` (корень).

---

### Шаг 3. Переменные окружения (Environment Variables)

В настройках контейнера в Cloud.ru добавьте следующие переменные:

| Переменная | Описание | Пример |
|---|---|---|
| `TELEGRAM_BOT_TOKEN` | Токен Telegram-бота от @BotFather | `8948316828:AAEi6oVo...` |
| `NODE_ENV` | Режим работы | `production` |
| `PORT` | Порт сервера | `3000` |
| `DATA_DIR` | Путь к постоянному хранилищу | `/app/data` |
| `DEFAULT_SIGMA_TOKEN` | Дефолтный токен SigmaSMS | `263eeb0e...` |
| `CHECK_INTERVAL_SECONDS` | Интервал фоновой проверки баланса (сек) | `60` |
| `ENCRYPTION_MASTER_KEY` | *(Рекомендуется)* Секретный ключ шифрования хранилища (от 32 символов) | `ЛюбаяСлучайнаяСтрокаОт32Символов` |

### Шаг 4. Постоянное хранилище данных (Persistent Volume) — КРИТИЧЕСКИ ВАЖНО

По умолчанию файловая система контейнера эфемерна (сбрасывается при перезапуске). Чтобы данные пользователей и зашифрованные токены сохранялись:

1. В настройках контейнера перейдите во вкладку **Тома / Volumes** (Хранилище).
2. Создайте и подключите диск/том (Persistent Volume).
3. Укажите путь монтирования внутри контейнера (**Mount Path**):
   ```
   /app/data
   ```
*Теперь вся база `bot_database.json` и защищенный Vault `data/.vault/` будут сохраняться при любых перезапусках и обновлениях контейнера.*

---

### Шаг 5. Сеть, порты и запуск

- **Порт контейнера**: `3000`.
- **Режим работы бота**: Long Polling (запускается автоматически при старте сервера, вебхук настраивать не требуется).
- **Ресурсы**: 0.5 – 1 vCPU, 512 MB – 1 GB RAM (этого более чем достаточно для обслуживания 200+ пользователей).
- **Healthcheck URL**: `/api/health`

После завершения деплоя бот сразу же выйдет в онлайн в Telegram, а по выданному Cloud.ru URL-адресу будет доступна полнофункциональная веб-панель управления!
